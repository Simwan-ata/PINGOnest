PingoNest ST1 Greenfield Architecture Charter

PingoNest ST1 is a zero-trust, multi-tenant enterprise orchestration platform for distributed resource clustering. It coordinates hierarchical organizations, isolated cluster boundaries ("Nests"), and registered endpoint instances ("Pingos") under a policy-governed, bi-temporally auditable operating model.

6 Bounded Contexts

1. Tenancy & Organization Context: Organization, Workspace, TenantQuota, Membership
2. Identity & Access Control (IAM): Subject, Account, RoleDefinition, RoleGrant, ScopeRegistry
3. Cluster & Resource Hierarchy: Nest (Cluster Domain), PingoNode (Registered Service)
4. Governance & Policy Context: GovernancePolicy, PolicyRule, ApprovalWorkflow, SoD Matrix
5. Temporal & Lifecycle State: StateTransitionEvent, BitemporalInterval, Supersession
6. Provenance & Audit Ledger: AuditTransactionRecord, SHA-256 Hash Chaining

Core Architectural Principles

  • Zero-Trust & Default-Deny: In the absence of an explicit valid grant covering scope and action, access is unconditionally denied.
  • Explicit Bitemporality: Real-world effective time (valid_from / valid_to) is strictly bifurcated from monotonic server recorded time (recorded_at).
  • Zero Historical Mutation: In-place physical UPDATE and DELETE statements are prohibited. Modifications occur via supersession records.
  • Cryptographic Audit Hash Chaining: Each tenant's audit trail forms an unbroken SHA-256 Merkle chain linking every state transition.

Architectural Decisions (ADR) & Schema

Architectural Decision Log

DEC-001: URN UUIDv4 Scheme

Prevents sequential auto-increment enumeration and multi-tenant key collision.

DEC-002: Explicit Bitemporality

Stores both effective_from/to and recorded_at for regulatory point-in-time replay.

DEC-003: Zero Hard Deletes

Soft terminal transitions (RETIRED / DECOMMISSIONED) preserve audit proof.

DEC-005: SHA-256 Ledger Chaining

Merkle link between sequential audit records detects any physical file tampering.
