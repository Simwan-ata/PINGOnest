# راهنمای اجرای نسخه پایتون سامانه مدیریت سازمان و فرآیند پینگو
# PingoNest Enterprise — Python Backend Architecture Guide

این سند راهنمای کامل راه‌اندازی و اجرای بک‌اند پایتونی سامانه **پینگو (PingoNest)** به همراه پایگاه داده **SQLite** و فرانت‌اند React است.

---

## ⚡ ۱. اجرای فوری و بدون نیاز به نصب هیچ پکیجی (Zero-Dependency)
فایل `server.py` به گونه‌ای طراحی شده است که با **کتابخانه استاندارد پایتون ۳** (شامل `sqlite3`, `http.server`, `json`, `threading`) به صورت چندنخی (Multithreaded) بدون نیاز به `pip` اجرا می‌شود:

```bash
# فقط کافی است این دستور را بزنید:
python3 server.py
# یا در ویندوز:
python server.py
```

پس از اجرا:
- سامانه در آدرس: `http://localhost:8000` در دسترس است.
- دیتابیس محلی به نام `database.sqlite` به طور خودکار ساخته می‌شود.
- یک فایل نسخه پشتیبان با فرمت خوانا به نام `data_store.json` نیز همگام‌سازی می‌گردد.

---

## 🚀 ۲. اجرای در حالت پرسرعت FastAPI (اختیاری)
اگر مایلید از فریمورک پیشرفته **FastAPI** و سرور ناهمگام **Uvicorn** بهره ببرید:

```bash
# نصب پیش‌نیازها
pip install -r requirements.txt

# اجرای سرور با ریلود خودکار
uvicorn server:app --reload --host 0.0.0.0 --port 8000
```

در این حالت مستندات تعاملی Swagger API نیز در آدرس زیر در دسترس خواهد بود:
- `http://localhost:8000/docs`

---

## 📦 ۳. بیلد فرانت‌اند برای ارائه کامل از طریق پایتون (Production Build)
برای اینکه فرانت‌اند کامل React نیز توسط سرور پایتون سرو شود:

```bash
# ۱. تولید کدهای بهینه‌سازی شده فرانت‌اند
npm run build

# ۲. اجرای سرور پایتون
python3 server.py
```
سرور پایتون به صورت هوشمند پوشه `dist/` را شناسایی کرده و کل سامانه (SPA) را همراه با فایل‌های گرافیکی، فونت‌ها و استایل‌ها به نمایش می‌گذارد.

---

## 📡 ۴. مسیرهای API موجود (Endpoints)
- `GET /api/health`: بررسی وضعیت آنلاین بودن سرور و دیتابیس
- `GET /api/org`: دریافت آخرین وضعیت چارت سازمانی، پروژه‌ها و فرآیندهای BPMN
- `POST /api/org`: ذخیره‌سازی داده‌های ساختار سازمانی در دیتابیس SQLite
- `GET /api/rbac/roles`: دریافت ماتریس دسترسی‌ها و نقش‌های سازمانی

---

## 🔒 ۵. امنیت و نگهداری دیتابیس
- دیتابیس `database.sqlite` تمام داده‌های ثبت‌شده را در جدول `org_store` ذخیره می‌کند.
- جهت جابجایی سامانه به سرور دیگر، فقط کافی است فایل‌های پروژه و فایل `database.sqlite` را کپی نمایید.
